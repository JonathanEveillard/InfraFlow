# InfraFlow

Build infrastructure visually. Deploy it reproducibly. Observe it in real time.

## Features

- Design, Monitor and Automate Infrastructure with ease with multi visual interaction tool
- Provision and Configure single/multi node cluster with IaC
- Observe analytical uptime across system
